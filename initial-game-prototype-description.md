The game features two main maps: an on-campus map and an off-campus map. Each main map contains multiple locations. When entering a location, the player is taken to a sub-map where specific events can be triggered.

Occasionally, special time-based events may occur, such as a sports festival. The game spans a total of four years, during which players can engage in activities such as studying and working to accumulate different stats.

At the end of the game, different endings are unlocked based on the player's accumulated stats and choices.
